# Data

Download the **Diabetes Dataset** (Rashid, 2020) from Mendeley Data:
<https://data.mendeley.com/datasets/wj9rwkp9c2/1> (DOI: 10.17632/wj9rwkp9c2.1)

Save the file in this folder as `Dataset of Diabetes.csv`.

The dataset holds records for 1,000 patients from two Iraqi hospitals with
age, gender, BMI, HbA1c, urea, creatinine, a fasting lipid profile and a class
label: `N` (non-diabetic), `P` (predicted diabetic) or `Y` (diabetic).
